# WebVerse – Interactive Web Technology Learning Platform

WebVerse is a responsive and interactive educational website designed to make learning Web Technology simple, engaging, and practical.

It provides structured syllabus-based learning resources, detailed topic explanations, interactive quizzes, visual diagrams, and a code playground where students can experiment with HTML, CSS, and JavaScript.

The platform is designed especially for students who want to understand Web Technology concepts step by step while practising their coding skills.

## 🌐 Live Demo

[Visit WebVerse](https://web-technology-learning-hub.vercel.app/)

## ✨ Features

- **Interactive Learning Dashboard:** Explore all five units through an organised learning interface.
- **Complete Syllabus Coverage:** 62 topics covering fundamental and advanced Web Technology concepts.
- **Detailed Topic Explanations:** Learn definitions, concepts, working mechanisms, real-world examples, diagrams, advantages, limitations, and important examination points.
- **Unit-wise Quizzes:** Test your knowledge with multiple-choice questions and instant feedback.
- **Visual Learning:** Understand concepts through interactive diagrams covering Client–Server Architecture, DNS, HTTP, AJAX, and Web Evolution.
- **Code Playground:** Write and execute HTML, CSS, and JavaScript with an isolated live preview.
- **Progress Tracking:** Mark lessons as completed and monitor your learning progress.
- **Dark and Light Themes:** Switch between two visually comfortable themes.
- **Responsive Design:** Access the platform on desktops, tablets, and mobile devices.
- **Local Progress Storage:** Save lesson completion, quiz scores, and theme preferences in your browser using LocalStorage.

## 🛠️ Technologies Used

- HTML5 – Website structure and content
- CSS3 – Styling, animations, layouts, and responsive design
- Vanilla JavaScript – Interactivity, quizzes, diagrams, and application logic
- LocalStorage – Saving learning progress and user preferences
- SVG – Visual diagrams and graphical elements

No frontend frameworks or backend server are required.

## 🚀 Run the Project Locally

**Step 1:** Clone the repository.

```bash
git clone https://github.com/sagarkapoor03/Web-Technology.git
```

**Step 2:** Open the project folder.

```bash
cd Web-Technology
```

**Step 3:** Open `index.html` in your browser.

You can also use the **Live Server** extension in Visual Studio Code for local development.

## 🌍 Deployment

WebVerse is deployed as a static website on Vercel.

Live Website:  
https://web-technology-learning-hub.vercel.app/

The project can also be hosted using other static website hosting platforms.

## 🎯 Project Objective

The main objective of WebVerse is to provide students with a single, interactive platform where they can study Web Technology concepts, practise coding, evaluate their understanding through quizzes, and track their learning progress.

It combines theoretical learning with practical activities to create a more engaging learning experience.
